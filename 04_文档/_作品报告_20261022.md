## 一、赛题理解与需求分析

赛题四要求：DVP/MIPI 摄像头采集 → FPGA 内灰度化、中值滤波、Sobel 边缘检测 → HDMI/VGA 显示；原始图像与边缘图像**分屏或叠加**；全流水线实时。

**基础要求**：① 采集 640×480+、行缓存、无丢帧/错位；② 灰度用 DSP/移位加法、无除法器；③ 3×3 Sobel、`G=|Gx|+|Gy|`、阈值可配、2 行缓存；④ HDMI ≥640×480@60、分屏或叠加、稳定无撕裂；⑤ 完整 RTL+约束+演示视频（棋盘格/数字纸/人脸）。

**高阶挑战**：① 3×3 中值滤波；② 实时阈值调节；③ 帧缓存与 DDR 控制；④ Canny；⑤ 边缘叠加彩色；⑥ 简易目标识别。

**本作品对应策略**：以 **DDR3 帧缓存**为核心，先保证基础五项与实时性，再按“DDR 帧缓存、彩色红边、中值滤波、Canny（两版）”逐项做高阶；实时阈值与目标识别作为后续/并行项。

## 二、系统总体方案

### 2.1 数据流

```
OV5640（DVP 8bit RGB565，640×480，排线反插）
  → DVP 采集（cmos_pclk）
  → 灰度 Y8 = (77R + 150G + 29B) >> 8
  → 12 条行缓存（3 条灰度 + 9 条 RGB）
  → 3×3 Sobel（G=|Gx|+|Gy|）+ 双阈值迟滞（LO=48/HI=64）
  → [可选] 3×3 中值（median3x3）/ Canny 两版（canny_core）
  → 写侧格式：RGB332（彩色+红边）或 8bit 灰度（分屏）
  → DDR3 帧缓存（4 块 × 4MB，顺序写/顺序读）
  → 读回 → 行缓冲 → [基础版] 2× 最近邻 / [高阶版] 1:1
  → TMDS（10:1 串行）→ HDMI 640×480@60Hz
```

### 2.2 时钟

| 时钟 | 频率 | 用途 |
|---|---|---|
| `cmos_pclk` | ~48 MHz（外部） | 摄像头像素域 |
| `clk_sys` | 96 MHz | UART/AXI 主控 |
| `clk_pixel` | 25.2 MHz | 显示像素域 |
| `clk_pixel_10x` | 126 MHz | TMDS 10× |
| `tdqss_clk/core_clk/tac_clk/twd_clk` | 384/192/384/384 MHz | DDR3 PHY/控制器 |

### 2.3 关键指标

| 指标 | 值 |
|---|---|
| 相机帧率 | **30.00 fps**（VTS=1688，`cam_period=3,200,448` @96MHz） |
| 显示 | **640×480@60Hz**（`disp_period=1,600,000`，hold=2 严格 2:1） |
| 存储分辨率 | 高阶 **640×480 全分辨率**；基础 320×240 + 2× |
| 帧缓存 | DDR3，4×4MB，顺序读写，无撕裂 |
| 逻辑资源 | RAM10 84–91/256（按 bit）；canny 核 9–12 块 |
| 时序 | 各 bit 最小 slack ≥ +0.026 ns，0 违例 |

## 三、关键模块设计

### 3.1 摄像头采集与灰度

- OV5640 DVP 8bit、RGB565；行缓存用 `line_buffer`/`frame_buffer`（BRAM，`ramstyle=block`）；
- 灰度：`Y8=(77R+150G+29B)>>8`，系数用移位加法实现，**无除法器**；
- 采集稳定：状态字 FF、30.00fps、行/场无错位（串口遥测 + 缩略图验证）。

### 3.2 Sobel 与迟滞

- 3×3 Sobel：`Gx/Gy` 由 9 个抽头移位加法得到；`G=|Gx|+|Gy|`；
- 双阈值迟滞：强边 `G>64`，弱边 `48<G≤64` 且左/上邻已是边缘才保留（8 连通生长）；
- 阈值可参数化配置（`SOBEL_THR/SOBEL_HI`）；实时按键调节为高阶 #2 的后续项。

### 3.3 DDR3 帧缓存（本项目核心）

- 官方 `DdrCtrl`（4×4MB buffer）+ `W0_FIFO_8` + `R0_FIFO_8` + `AXI4_AWARMux` + `axi4_ctrl`，**IP 未升级、FIFO 参数未改**；
- 写侧按 1024B burst 顺序写，显示侧顺序读；4 块轮转避免读写撞块；
- **P0 修复**：① 相机 51.46fps ↔ 60Hz 非整数比 → VTS 984→1688（30.00fps，hold=2）；② 写侧 EOF 由“地址回绕”改为**摄像头帧边界 `frame_end`**，消除 CDC 延迟导致的新帧字节混入旧 buffer（整幅左右抖动）；
- **B1 全分辨率**：写/读 476×638 = **303,688 B/帧**；地址 19 位、`rd_col` 10bit、关掉放不下的时域 IIR；RAM10 91、0 违例；
- 第 42 轮修复保留：`waddr_d` 只在 `we` 时更新。

### 3.4 3×3 中值滤波（高阶 #1）

- 模块 `median3x3.v`（同学交付）：纯组合 19 比较器、9 抽头→中值、**0 块 RAM10**；
- 集成：复用 Sobel 3×3 窗口抽头，替换显示/写帧缓存的中心像素；build 0 违例（基础分屏版）；
- 说明：该接法只影响显示灰度，Sobel 邻域未滤波，**边缘图不变**；严格“Sobel 前中值”需另加 2 行缓存（后续项）。

### 3.5 Canny（高阶 #4，两版）

- 模块 `canny_core.v`，参数 `GAUSS_EN`：
  - `GAUSS_EN=0`：简化版（Sobel→方向量化→NMS→双阈值+滞后）；
  - `GAUSS_EN=1`：严格版（3×3 高斯 1-2-1→Sobel→…）；
- 方向量化：`|Gx|/|Gy|` 比值 → 0/45/90/135°，**不做 atan/CORDIC**；
- NMS：3 行 mag/dir 行缓存 + 拍链；对角方向用“上斜两邻”近似；滞后为简化生长；
- 行缓存：raw 3 行 + gauss 3 行 + mag/dir 3 行，全部同步 BRAM（`line_buffer`），LUT 从 98k 降到约 6k；
- 延迟约 1 行 + 4 拍；集成时写地址用 1 行延迟 FIFO 对齐；
- 两版 bit 均已上板（2026-10-29）：肉眼看不出明显差异；选**严格版**作为交付（高斯平滑更符合 Canny 定义，bit 更小）；未观察到明显整体偏移（若后续发现，按 `canny_edge` 延迟调整）。

### 3.6 边缘叠加彩色（高阶 #5）

- `EDGE_COLOR=1`：RGB332 彩色 + 边缘像素强制红色 `0xE0`；时域两帧 AND 降闪烁；
- 全分辨率 640×480 上板确认“明显更清晰”。

### 3.7 基础分屏（基础 #4）

- 320×240 存储 + 2× 显示，左半屏原始灰度 / 右半屏 Sobel 边缘；
- 左右两半共用一套取数，DDR 流每帧完整消费；中央接缝连续；上板确认“很好”。


### 3.8 实时阈值调节（高阶 #2）

- 模块 `thr_ctrl.v`：K1/K2 两级同步 + 消抖（`DEB_CNT=2^20`，约 11 ms@96MHz）、步进 8、`hi=lo+16`、clamp 8..232、按住连发；
- 阈值同时接 Sobel 迟滞与 Canny 的 `thr_lo/thr_hi`，复位值 48/64，不按键时画面与改动前一致；
- 资源约 111 FF / 0 RAM10；仿真 9 项断言 PASS（消抖/步进/clamp/同按）。

### 3.9 简易目标识别（高阶 #6）

- 模块 `shape_detect.v`：帧级统计（0 RAM10）：
  - 孤立点剔除（上/左/左上支持）+ ROI 门控（x 64..575, y 48..431）；
  - 本帧 bbox + 上帧 bbox 的边框重合度：>70% 判矩形，15%~70% 且长宽比 0.70~1.43 判圆，否则无目标；
- 输出 bbox/class 经翻转锁存跨到 `clk_pixel`，显示 2px 白框 + 左上角 16×16 状态块（空心圆/实心方）；
- 资源约 769 FF / 0 RAM10；A 修复了 C 交付的三个问题：`edge` 是 Verilog 关键字（改 `edge_i`）、仿真 tb 在 posedge 驱动导致竞争（改 negedge 驱动后 PASS）、x/y 改由顶层 `pcol/row_d1` 直接输入；
- 上板测试待做（K1/K2 调阈值；圆/方纸片识别）。


### 3.10 全分辨率增强版（2026-11-02）

- 在 B1 全分辨率彩色+红边源码上叠加 **实时阈值（thr_ctrl）** 与 **简易目标识别（shape_detect）**；
- 识别框叠加在彩色全屏画面上：白框 + 目标框左上角 16×16 状态块（空心圆/实心矩形）；
- 资源：RAM10 **91/256**、min slack **+0.026 ns**、**0 违例**；bit 1,937,550 B；
- 默认阈值 48/64（= 早期固定阈值，上电即干净）（= 原来 K1 按 3 次后的干净画面）；识别 ROI 收紧到中心 240×180；
- 说明：识别算法基于**边缘图**（Sobel 边缘），颜色只影响显示观感，不影响检测；需要干净背景、单目标、目标占满 ROI；全分辨率彩色版演示效果最好，推荐作为高阶主推；
- A 在集成中发现并修复：C 原 `shape_detect` 的 `edge` 端口是 Verilog 关键字（改 `edge_i`）；tb 在 posedge 驱动导致竞争（改 negedge，PASS）；x/y 由顶层坐标改为 **de 流内部计数**（避免采集域与 Sobel 域延迟错位，这是首次上板无识别框的根因）。

## 五、创新点与亮点

1. **DDR3 帧缓存**：把 150 块 BRAM 的帧缓存搬到 DDR3，片内只留行缓冲，为全分辨率/新功能腾出资源；
2. **P0 根因定位**：用串口遥测+缩略图把“抽动”拆成“帧率非整数比”和“写侧 EOF 回绕”两个可修复问题；
3. **全分辨率 640×480**：写读严格 303,688 B/帧、0 违例；
4. **两版 Canny**：同步 BRAM 行缓存 + 抽头链，资源可控（canny 核 9–12 块 RAM10），可现场对比“简化/严格”；
5. **多形态显示**：全屏彩色+红边、左右分屏、基础+中值，适配基础/高阶演示。

## 六、演示方案

- 基础：棋盘格、印大号数字/字母的纸、人脸轮廓 → 左右分屏（左灰度/右边缘）；

- 视频：3 段（基础中值 / 高阶全分辨率 / Canny 严格），总时长 ≤5 分钟，手机固定机位，640×480 HDMI 输出。

## 七、已知问题与改进方向

1. **P1 固定曝光**：AEC 仍开，缩略图均值 ±5 缓慢回摆；手动曝光/增益寄存器映射待查数据手册（不阻塞）；
2. **Canny**：两版均上板、选严格版；对角 NMS/滞后为简化实现；未观察到明显偏移（若发现，调 `canny_edge` 延迟重构建）；
3. **实时阈值调节（高阶 #2）与目标识别（高阶 #6）**：设计中/未集成，按实际提交时如实说明；
4. **真·前置中值**：让 Sobel 邻域也吃中值需 +2 行缓存、2 行对齐，后续项；
5. **目标识别**：单目标、需干净背景、约 2 帧滞后（66 ms）；这是“简易识别”的定位，演示时把形状画在纸上；
6. **光照频闪**：LED/日光灯下卷帘快门会出现斜向明暗带（重新上电才消失，重烧 FPGA 不会重置摄像头）；演示建议用非频闪光源，后续可加 OV5640 抗闪烁寄存器。
5. **基础版分辨率口径**：基础分屏为 320×240 存储，基础五项演示优先用高阶全分辨率 bit。

## 八、总结

本作品以 DDR3 帧缓存为核心完成了 640×480 全分辨率实时边缘检测：P0 抽动已关闭、30.00fps/60Hz/hold=2、时序 0 违例；高阶完成 DDR 帧缓存、彩色红边、中值滤波、Canny（严格版）、实时阈值与简易目标识别（增强版 bit，待上板）；基础五项（采集/灰度/Sobel/HDMI/分屏）均有可上板 bit。剩余工作集中在增强版上板、视频录制、报告定稿与 11/4 提交。
