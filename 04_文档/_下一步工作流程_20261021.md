## 3. 统一接口约定（所有新模块必须遵守）

1. **像素流**：`clk`、`rst_n`、`de`（有效像素）、`din`、`de_out`、`dout`；`de=1` 时每拍一个像素；**固定延迟**，文件头写清（几行+几拍）。
2. **时钟域**：视频流水线用 `cmos_pclk`；显示用 `clk_pixel`；跨域只用 2FF 同步/寄存器，禁止组合跨域。
3. **复位**：统一 `rst_n`。
4. **Verilog**：可综合 Verilog-2001；无 latch、无 initial、无 `$display` 进综合；位宽显式。
5. **资源**：文件头写明预估 LUT/RAM10/DSP；RAM10 预算见任务表。
6. **仿真**：每个模块配 `tb_<module>.v`，自检（PASS/FAIL），用 iverilog 跑；提交附「仿真命令 + 结果」。
7. **放置**：源文件放 `E:\efinity_project\104.2\<module>.v`（综合用），工作区根目录留一份；tb 放 `E:\efinity_project\104.2\tb\`。
8. **命名**：文件 `snake_case.v`；端口小写；参数大写。

## 4. 各模块接口契约

### 4-A. A：`frame_freeze` / 顶层集成

- `frame_freeze`：输入 `key_freeze`（**M2 = ball M2 = GPIOL_N_02**，默认上拉，低有效）、时钟/复位；冻结写指针/保持读 bank；LED 指示。
- 顶层：实例化 B/C 模块、注册 XML、引脚、构建、最终 bit；`camera_hdmi.v` 仅 A 编辑。

### 4-B. B：`canny_core`（新）—— 高阶 #4

```verilog
module canny_core #(
    parameter [7:0] THR_LO = 8'd48,
    parameter [7:0] THR_HI = 8'd64
)(
    input  wire       clk,        // cmos_pclk
    input  wire       rst_n,
    input  wire       de,
    input  wire [7:0] din,        // 灰度输入
    input  wire [7:0] thr_lo,     // 运行时阈值（来自 C 的 thr_ctrl）
    input  wire [7:0] thr_hi,
    output wire       de_out,
    output wire       edge_o   // 不能叫 edge（Verilog 关键字）        // 1 = 边缘
);
```

- 流水：3×3 高斯（1-2-1，移位）→ Sobel → 方向量化（0/45/90/135°，比值比较，**不做 atan/CORDIC**）→ 3×3 NMS → 双阈值+滞后。
- 延迟：文件头写明（建议 4 行+4 拍）；内部行缓存 ≤6 行（≤6 块 RAM10）；禁止除法器/DSP 乘法。
- tb：棋盘格/圆/矩形合成图；对比 Sobel：单像素细边、连续、噪点少；PASS/FAIL。
- DoD：仿真通过 + 延迟表 + LUT/RAM 预估 + 参数说明。

### 4-C. C：`thr_ctrl` + `shape_detect` + 流水线补丁

#### C1. `thr_ctrl.v` —— 高阶 #2

```verilog
module thr_ctrl #(
    parameter [7:0] INIT_LO = 8'd48,
    parameter [7:0] INIT_HI = 8'd64,
    parameter [7:0] STEP    = 8'd8
)(
    input  wire       clk,        // cmos_pclk
    input  wire       rst_n,
    input  wire       key_plus,   // K1，低有效，异步
    input  wire       key_minus,  // K2，低有效，异步
    output reg  [7:0] thr_lo,
    output reg  [7:0] thr_hi
);
```

- 2FF 同步 + 10ms 消抖；每次 ±STEP；clamp 8..248；`thr_hi = thr_lo + 16`（或独立，写清）。
- 引脚：**K1 = ball K1 = GPIOL_P_07；K2 = ball K2 = GPIOL_N_06**（A 加到 peri/isf）。
- tb：按键序列（加/减/长按/抖动）→ 验证步进/clamp/复位值。
- DoD：仿真通过 + 资源（约 50 FF）+ 与 `camera_hdmi.v` 的接线说明。

#### C2. `shape_detect.v` —— 高阶 #6

```verilog
module shape_detect (
    input  wire        clk,          // cmos_pclk
    input  wire        rst_n,
    input  wire        de,           // 边缘流有效
    input  wire        edge,         // 1 = 边缘
    input  wire        frame_start,  // 帧起始脉冲（frame_end 或 vsync）
    output reg  [9:0]  bbox_x0, bbox_x1, bbox_y0, bbox_y1,
    output reg  [1:0]  shape_class,  // 0=无, 1=圆, 2=矩形
    output reg         valid         // 帧末更新，保持到下一帧
);
```

- 帧级统计：bbox（min/max x/y）、边缘像素数、bbox 边框重合度、长宽比；帧末分类。
- 判定建议：矩形 = 边缘大多落在 bbox 四条边上；圆 = 长宽比≈1 且边框重合度低。
- 资源：0 块 RAM10（计数器/寄存器）；输出寄存器在 `cmos_pclk`，A/C 负责同步到 `clk_pixel`。
- tb：合成圆/矩形 edge 帧；验证 class 与 bbox；PASS/FAIL。
- DoD：仿真通过 + 分类门限说明 + 资源预估。
- 算法评审：分类门限可由 B 给建议（B 不改 C 的代码）。

#### C3. 流水线补丁（C 给，A 合并）

- **阈值钩子**：Sobel 迟滞比较 `sobel_v > SOBEL_HI/THR` → `> thr_hi/thr_lo`（来自 `thr_ctrl`）。
- **中值/平均钩子**：已整合（`gd2_fin` 路径）；如需高阶红边也吃中值，另做真前置中值。
- **Canny 模式钩子**：`EDGE_SRC` 参数（0=Sobel，1=Canny），把 `canny_core` 的 `edge` 接到写缓存 `edge_data`。
- **识别钩子**：`shape_detect` 的 bbox/class 同步到 `clk_pixel`，显示段画包围框（A 的显示段）。

## 7. 上板交接协议（A 主责，B/C 随时可接）

**默认**：板子在 A 手上，A 主责；每次板测前 C 给「bit 列表 + 每个 bit 看什么 + 期望串口值」。

**接手人（B/C）操作清单**：
1. 硬件：电源、FTDI 下载器、CH340 串口、HDMI、OV5640（反插）；**K3 配置键不碰**；烧完等 **≥5 秒**；
2. 烧对应 bit（GUI Programmer；FTDI 必须 libusb-win32）；
3. 跑 `_final_check.ps1 6 --png`，期望 **FF / 30.00fps / 60Hz / hold=2**；
4. 拍/录 HDMI 画面（固定机位）；
5. 回填 `_板测记录_YYYYMMDD.md`（模板 `_板测记录模板.md`）：bit 路径、PASS/FAIL、现象、照片/视频路径；
6. 异常先烧回已知好 bit（`..._1057_b1_fullres.bit` / `..._1113_split_lr_320.bit`）确认硬件，再报 A/C。

**交接物**：板子 + 摄像头 + HDMI 线 + 电源 + 下载器 + 串口线 + `_bitbk/` 已知好 bit 列表。
**原则**：没有 `_板测记录` 视为未测；Gate 决策以记录为准。

## 8. 风险与红线

| 风险 | 应对 |
|---|---|
| B 的 Canny 时序/画质不达标 | 10/27 Gate 回退 Sobel，砍 #4 |
| C 的识别分类不稳 | 10/29 Gate 降级为 bbox 检测，不算 #6 |
| C 任务多（阈值+识别+补丁+验证） | 阈值先做（10/23 独立完成）；识别 10/24 启动；验证由 A 的 agent 自动出报告 |
| 多人改顶层冲突 | `camera_hdmi.v` 仅 A 合并；B/C 交文件/补丁 |
| 新功能时序违例 | 1 天内收不了就砍；0 违例优先 |
| 板测时间不可控 | 一次构建多 bit、集中烧；仿真先行 |
| 报告/视频被挤占 | 报告框架并行；P6 只做打包/录制 |

**红线**：不升级 IP、不改 FIFO 参数、不往 `tac_clk` 插逻辑、保留第 42 轮修复、时序 0 违例、基线可复现。
