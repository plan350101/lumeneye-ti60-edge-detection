## 2. Canny 模块怎么开始（T4 → T2）

### 2.1 先定接口（T4，10/23 前）

```verilog
module canny_core #(
    parameter [7:0] THR_LO = 8'd48,
    parameter [7:0] THR_HI = 8'd64
)(
    input  wire       clk,        // cmos_pclk
    input  wire       rst_n,
    input  wire       de,
    input  wire [7:0] din,        // 灰度
    input  wire [7:0] thr_lo,     // 来自 C 的 thr_ctrl
    input  wire [7:0] thr_hi,
    output wire       de_out,
    output wire       edge_o   // 不能叫 edge（Verilog 关键字）
);
```

- 延迟目标：**4 行 + 4 拍**（先按这个设计，文件头写死；后面可调）。
- 行缓存预算：≤6 行（每行 640×8 → 1 块 RAM10/行）。
- 禁止：除法器、DSP 乘法、atan/CORDIC。

## 12. T8 首次集成构建发现（2026-10-22）：异步读数组 → LUT 爆炸

- 集成 patch 已写入 320 分屏源码（EDGE_SRC + canny 例化 + 1 行地址延迟 FIFO），patch 全部命中；
- 第一次 `efx_map` 结果：**LUT4 98,071**（基线约 5,800）、FF 46,180、RAM10 75，map 耗时 850 s；
- 原因：`canny_core.v` 里 raw/gauss/mag 三个 ring 用**组合读数组**（`assign p11 = raw[...]`），Efinity 推断成 **LUTRAM/寄存器**，不是 BRAM；
- 结论：远超 Ti60 可用逻辑资源，PnR 必挂；已停止该次构建（未产生 bit）；
- **修复方案**：把 canny 的 3 组行缓存改成**同步读 BRAM 行缓存 + 抽头移位链**（与顶层 Sobel 的 `u_gl0/1/2` + `r1_t1/t2` 同款）：
  - raw 3 行、gauss 3 行、mag/dir 3 行 → 约 9 块 RAM10；
  - 同步读有 1 拍延迟，窗口/当前行像素要相应延迟 1 拍；
  - 预计 LUT 回到 1–2k 量级；
- 修复后再构建 `EDGE_SRC=1/2` 两版，归档 bit，留待上板。
