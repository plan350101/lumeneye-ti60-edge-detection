## 2. 资源与延迟（给 A 做 RAM10 预算）

| 模块 | FF | LUT4 | RAM10 | DSP | 时钟域 |
|---|---:|---:|---:|---:|---|
| `thr_ctrl` | ~55 | ~60 | **0** | 0 | `cmos_pclk` |
| `shape_detect` | ~1300* | ~250 | **0** | 0 | `cmos_pclk` |
| P4 CDC（显示段） | ~50 | ~10 | 0 | 0 | `clk_pixel` |
| P5 绘制 | ~0 | ~40 | 0 | 0 | `clk_pixel` |
| **合计** | ~1400 | ~360 | **0** | 0 | |

\* `shape_detect` 里那条 640 位行移位寄存器会被综合器吸收成 SRL8（约 80 个），
所以实际 FF 增量约 **700** 左右。**RAM10 净增 0**，分屏版仍应保持 83。

延迟：

| 项 | 值 | 说明 |
|---|---|---|
| `thr_ctrl` 按键 → 阈值生效 | `DEB_CNT + 2` 拍 | 默认 2^20，即 10.9 ms@96MHz / 43.7 ms@24MHz |
| `shape_detect` 帧末 → 分类输出 | 1 拍 | 在 `frame_start` 那拍更新 |
| 画面内容 → 分类结果 | **2 帧 ≈ 66 ms** | 1 帧算 bbox，1 帧算边框重合度 |
| bbox 跨到显示域 | 2~3 个 `clk_pixel` | 翻转锁存，只在帧边界取样 |

## 3. 算法与判据

### 3.1 为什么用「包围框 + 边框重合度」

| 形状 | 边缘落点 | 边框重合度（实测） |
|---|---|---|
| 矩形 | 全部落在 bbox 四条边上 | **≈ 100 %** |
| 圆 | 只有 4 个切点碰 bbox | **20 ~ 53 %**（随半径变，见下表） |
| 背景杂物 | 散落在框内，不贴边 | **≈ 0.3 %** |

圆在 640×480 下随半径变化的实测值（TOL=3）：

| r | 30 | 40 | 50 | 60 | 80 | 100 | 120 | 150 | 180 |
|---|---|---|---|---|---|---|---|---|---|
| 边框重合度 | 52.7% | 44.2% | 40.9% | 37.1% | 32.1% | 28.6% | 25.5% | 22.8% | 20.7% |

→ 判据取 **70 %** 分界，圆的余量 ≥ 17 个百分点，很安全。

### 3.2 判据（全部用整数交叉相乘，无除法器）

```
cnt_e < 350 或 bbox 任一边 < 60            -> 0 = 无目标
cnt_b * 100 >  cnt_e * 70                  -> 2 = 矩形
cnt_b * 100 >= cnt_e * 15  且  0.70 <= w/h <= 1.43 -> 1 = 圆形
其余                                        -> 0 = 无目标
```

### 3.3 三道抗噪措施

1. **孤立点剔除**：边缘像素必须在 上 / 左 / 左上 里至少有一个也是边缘，才计入。
   一行 640 个点在 `de` 上移位，正好构成"上一行"。
2. **ROI 门控**：只统计 `x∈[64,575]`、`y∈[48,431]`，把桌沿、画面四边排掉。
3. **上一帧 bbox 有校标志 `pb_ok`**：上一帧是空帧时本帧不数边框像素
   （否则 `x >= 0-TOL` 恒真，整帧都会被当成"边框"→ 错判成矩形）。

### 4.2 你要做的（有 iverilog 的机器上）

最省事：双击或执行

```powershell
powershell -ExecutionPolicy Bypass -File .\run_sim.ps1
```

会依次编译并运行两个 tb，最后打印 `===== 全部 PASS =====`。
（没装 Icarus Verilog 的话，脚本会提示下载地址：http://bleyer.org/icarus/ ）

手工等价命令：

```bash
cd 目标识别

# thr_ctrl
iverilog -g2005 -o tb_thr.vvp tb_thr_ctrl.v thr_ctrl.v
vvp tb_thr.vvp            # 期望最后一行：***** TB PASS *****

# shape_detect
iverilog -g2005 -o tb_sd.vvp tb_shape_detect.v shape_detect.v
vvp tb_sd.vvp             # 期望最后一行：***** TB PASS *****
```

两个 tb 都生成了 `*.vcd`，可用 GTKWave 看波形交报告。

> 若 iverilog 报 `$dumpvars` 相关错误，删掉 tb 里那两行 `$dumpfile/$dumpvars` 即可，
> 自检逻辑不依赖波形。

## 5. 上板演示脚本（给 A 的板测清单）

**准备道具**：白纸一张，画一个直径约 8 cm 的**圆**；另一张画**正方形**。
（直径选 8 cm 是因为在 30 cm 距离下约对应 200~260 像素，正好落在最稳的区间。）

**步骤**：

| # | 操作 | 期望 |
|---|---|---|
| 1 | 烧 bit，等 5 s | 串口 `FF / 30.00fps / 60Hz / 2` |
| 2 | 不按键，对着墙面 | 与中值版画面一致，无白框 |
| 3 | 连按 K1 三次 | 边缘明显变少（阈值 48→72） |
| 4 | 连按 K2 三次 | 边缘明显变多（回到 48 以下） |
| 5 | 举圆纸、铺满画面中央 | 白框 + 左上角**空心**状态块 |
| 6 | 换正方形 | 白框 + **实心**状态块 |
| 7 | 移开纸张 | 框消失（不会残留） |

**拍视频要点**：先拍按键调阈值那一段（最能体现"实时"），再拍圆↔方切换。
每次切换**停 1 秒以上**再看，因为分类有 2 帧（66 ms）滞后 —— 别在切换瞬间截图。

## 7. 已知限制（写进报告，别让评委先问出来）

1. **单一目标**：本模块只输出**一个** bbox，画面里同时有多个物体时会框住整体。
   这是"简易目标识别"的定位，赛题原文就是「简易」。
2. **需要干净背景**：背景越花，bbox 越容易被撑大 → 触发 `MIN_EDGE`/重合度门限判 0。
   演示时把形状画在纸上、让纸张占据画面主要区域即可。
3. **颜色不是判据**：只看几何，不看颜色。黑纸白底 / 白纸黑底都行。
4. **2 帧滞后**：bbox 要整帧结束才知道，边框重合度只能拿上一帧的框去数。
   静态展示无感，快速挥动会滞后约 66 ms。

## 8. 风险与回退（对齐 §8 风险表）

| 风险 | 触发条件 | 回退动作 |
|---|---|---|
| 分类不稳 | 10/29 Gate 不过 | 只留 bbox，不出类别 → 「降级为 bbox 检测，不算 #6」 |
| 引脚对不上 | K1/K2 球号与实物不符 | 只改 `.isf` 两行 `assign_pkg_pin`，RTL 不动 |
| 时序违例 | 新逻辑进 `cmos_pclk` 后 slack < 0 | `shape_detect` 的累加/比较都在帧末单拍完成，是最大组合路径；先试 `LINE_GAP` 不变、把 `MIN_EDGE` 比较改成寄存器输出；仍不过就把 `shape_detect` 整块砍掉 |
| 占用超预期 | RAM10 > 83 | 不可能（两个模块 0 块 RAM10），若真超了说明 P7 注册错了文件 |
