## 一、赛题四原文要点

**任务**：DVP/MIPI 摄像头采集 → FPGA 内灰度化、中值滤波、Sobel 边缘检测 → HDMI/VGA 显示；原始图像与边缘图像**分屏或叠加**；全流水线、实时。

**基础要求**：
1. 摄像头驱动与采集：分辨率 **640×480 或以上**；存入行缓存；无丢帧、无错位。
2. 彩色转灰度：用 DSP 或移位加法，**避免除法器**。
3. 3×3 Sobel：Gx/Gy、`G=|Gx|+|Gy|`、阈值可配、2 行缓存。
4. HDMI 显示：标准时序 **≥640×480@60Hz**；**分屏**（左/上灰度、右/下边缘）**或画中画叠加**；稳定无闪烁/撕裂。
5. 基础验证：完整 RTL + 约束；**演示视频**（摄像头对棋盘格、印数字的纸、人脸轮廓等展示边缘效果）。

**高阶挑战（6 项，任选加分）**：
1. 3×3 中值滤波（灰度化后、Sobel 前，9 像素排序网络）。
2. **实时阈值调节**（板载按键/拨码 + 消抖 + 阈值寄存器；按 + 边缘减少、按 - 边缘增多）。
3. 帧缓存与 DDR 控制（外部 DDR，采集-存储-读取分离，Efinity DDR 硬核 IP；可回放/冻结/多帧对比）。
4. Canny 边缘检测。
5. 边缘叠加彩色输出（红边叠加到彩色图）。
6. 简易目标识别（圆形/矩形等）。

**提交与日程**（第一轮通知）：
- 报名：2026-07-06 ~ 09-22 24:00（官网 www.socchina.net）；每队 ≤3 人、≤2 名指导老师。
- **作品提交截止：2026-11-04 18:00**；初赛提交**作品报告 + 视频**，线上评审。
- **决赛：2026-11-20 ~ 22，南京江北新区**；决赛含 FPGA 基础编程考核 + 现场演示答辩。

## 三、差距与建议动作

### A. 实时阈值调节（高阶 #2，建议优先）

- 赛题明确要求“通过**板载按键或拨码开关**实时调整”，并称其为“性价比最高的加分项”。
- 板载按键引脚已从 HDK 查到：
  - **K1 = ball K1 = GPIOL_P_07 = User_IO21**
  - **K2 = ball K2 = GPIOL_N_06 = User_IO2**
  - K3 = GPIOL_P_06（**配置键，不要用**）；KEY0=N2（当前 `rst_n`）；KEY1=M2（默认上拉，备用）
- 实现方案：新增 `key_plus`/`key_minus` 输入（弱上拉、低有效）→ 2FF 同步 + 10ms 消抖 → 阈值寄存器 `thr_lo/thr_hi`（初值 48/64，步进 ±8，clamp 8..248）→ 替换 `SOBEL_THR/SOBEL_HI` 参数；可同时用于高阶版与基础版。
- 成本：+2 个普通 IO、约 100 LUT、0 块 RAM10；时序/带宽无影响。
- 验收：按 K1 边缘减少、K2 边缘增多；状态字仍 FF、30fps/60Hz/hold=2；0 违例。

### B. 演示视频内容（基础 #5）

赛题原文要求对**黑白棋盘格、印有大号数字/字母的纸、人脸轮廓**演示边缘效果。录制清单已按此更新（原清单偏“平移/键盘特写”）。

### C. 基础版分辨率

基础分屏版存储 320×240（显示 640×480）；若评委严格看“存储/处理分辨率”，**基础五项建议用高阶全分辨率 bit 演示**，分屏版作为加分演示。或后续把分屏做成全分辨率（此前因 DDR IP 内部 `core_clk→twd_clk` -0.015ns 违例未采用，可换 PnR 种子/布局再试）。

初赛需“作品报告 + 视频”，格式“另行通知”。当前已有 `_技术报告_DDR3帧缓存_20261020.md`（可直接扩展为报告主体），包内 README/交接文档可作为附录。
